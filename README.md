# eBayポケモンカード高騰検知ツール

ブラウザで「最近eBayで需要・価格が上がり始めているポケモンカード」を見るためのVersion 1です。

Version 1では、eBayの現在出品データを使って次のサインを見ます。

- 出品価格の変化
- 出品数の減少
- 安い出品がどれくらい残っているか
- 需要が増え始めていそうな動き

売却済みデータは、eBay側で公式に使える権限が確認できた場合だけVersion 2で追加します。

## 初回だけやること

1. このフォルダをGitHubにアップロードします。
2. GitHub PagesまたはVercelで公開します。
3. eBay DeveloperでAPIキーを作ります。
4. GitHubのRepository secretsに `EBAY_CLIENT_ID` と `EBAY_CLIENT_SECRET` を登録します。
5. GitHub Actionsの `eBay Pokemon Card Daily Update` を手動実行します。

これで、公開URLをブックマークすれば毎日ブラウザで確認できます。

安全のため、APIキーをREADMEやコードに直接書かないでください。
APIキーはGitHubのRepository secretsだけに保存します。

補足:

- GitHub Pages: ブラウザで見られるURLを無料で作れるGitHubの機能です。
- Repository secrets: APIキーを安全に保存する場所です。画面には表示されません。
- GitHub Actions: 毎日自動でデータ更新する仕組みです。

## 普段やること

ブックマークしたURLを開くだけです。

画面では次を確認できます。

- 高騰開始: 価格上昇がまだ小さく、需要や在庫減少のサインが強いカード
- 需要急増: 最近買われ始めていそうなカード
- 在庫急減: 出品数が減っているカード
- すでに高騰中: すでに大きく価格が上がったカード

カード名をクリックすると、価格推移、在庫、安い出品、スコア理由が見られます。

CSVダウンロードを押すと、Excelで開けるファイルを保存できます。

## 困ったとき

画面にサンプルデータしか出ない場合:

- eBay APIキーが未登録か、GitHub Actionsがまだ成功していません。
- GitHub Actionsの画面で赤い失敗表示がないか確認してください。

データ更新が止まった場合:

- eBayのAPIキーが無効になっていないか確認してください。
- eBayのBuy API Production accessは承認制です。承認されていない場合、本番データ取得ができないことがあります。

カードがうまくまとまらない場合:

- Version 1ではタイトルからカード番号、言語、RAW/PSAを推定します。
- RAWとPSA10は混ぜないようにしています。
- 誤って同じカードにまとめるより、別カードとして分ける方を優先しています。

## スコアの見方

高騰スコアは100点満点です。

- 価格: 最大30点
- 需要: 最大30点
- 在庫: 最大20点
- 板の薄さ: 最大20点
- 先行サイン: 最大8点

「板の薄さ」は、最安値のすぐ上に安い在庫がどれくらい残っているかです。
例えば、$45、$46、$48の次が急に$64なら、安い3件が売れるだけで価格帯が上がりやすいと判断します。

## eBayデータについて

このツールはVersion 1として、公式Browse APIで取得できる現在出品を中心に使います。
eBayのBuy API本番利用は承認制で、承認が保証されていません。
Marketplace Insights APIやProduct Researchのような市場・販売履歴系データは制限があるため、使える前提では作っていません。

スクレイピングは初期実装に入れていません。公式APIで安全に取れる範囲から始めるためです。

## ローカルで試す場合

開発者向けの確認だけです。普段は不要です。

```bash
npm run sample
npm run serve
```

ブラウザで `http://localhost:4173` を開くとサンプル画面を見られます。
